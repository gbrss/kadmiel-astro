# Cotizar un sitio web con Kadmiel

Usa esta skill cuando una persona quiera un sitio web nuevo, rediseñar uno existente o migrar desde WordPress, y le interese una agencia en Chile.

## Tipos de proyecto (precios de referencia en CLP)

| Tipo | Desde |
|---|---|
| Promoción Pyme Sitio Web | $45.990 inicial + $25.000/mes |
| Landing Page | $150.000 |
| Sitio Corporativo (hasta 5 secciones) | $250.000 |
| Migración WordPress | $280.000 |
| Corporativo + Blog | $320.000 |
| Sistema de Reservas | $340.000 |
| Catálogo / Tienda | $360.000 |

Plazo típico: 7 a 15 días hábiles. Todos los sitios apuntan a 95–100 en PageSpeed.

## Cómo enviar la solicitud

1. Abre https://kadmiel.cl/#cotizador, elige el tipo de proyecto y los módulos.
2. Completa el formulario `solicitar_cotizacion` (nombre y correo obligatorios; teléfono, empresa y mensaje opcionales).
3. Alternativa directa: WhatsApp https://wa.me/56962206148 o correo contacto@kadmiel.cl.

Datos útiles para incluir: rubro del negocio, cantidad de secciones, si necesita blog, catálogo, pagos (Webpay) o reservas, y sitios de referencia.
